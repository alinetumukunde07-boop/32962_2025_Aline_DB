# Phase 1: Problem Statement - Payroll Tax Management System
**Project Name:** 32962_2025_Aline_DB  
**Author:** Aline  

## 1. Problem Definition
Traditional payroll and tax management systems often suffer from manual computation errors, lack of real-time tax bracket updates, delayed statutory reporting, and poor audit trails. This project automates employee compensation, calculates tiered income taxes dynamically, manages deductions, and generates audit-ready compliance reports.

## 2. Context of Use
Designed for small-to-medium enterprise (SME) HR and Finance departments to securely process monthly payroll, apply up-to-date tax legislations, and maintain transparent employee pay history.

## 3. Target Users
* **HR Managers:** Manage employee profiles, salary structures, and department data.
* **Payroll Officers:** Run monthly payroll calculations, review tax withholdings, and generate payslips.
* **System Administrators:** Manage database users, roles, privileges, and auditing security policies.
* **Employees:** View individual payslips and tax deduction summaries.

## 4. Project Objectives
* Design a fully normalized relational database (up to 3NF) using Oracle SQL.
* Implement robust business logic using PL/SQL packages, procedures, functions, and triggers.
* Enforce fine-grained security, user privileges, and Oracle Database Auditing.
* Provide error-free, automated payroll calculation with zero manual discrepancies.

## 5. Expected Benefits
* Elimination of calculation errors for statutory taxes.
* Instant generation of payslips and regulatory tax reports.
* Secure, role-based access control protecting sensitive financial data.
